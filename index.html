Roblox 工作室 使用說明

這是在瀏覽器裡跑的 Roblox 風格 Luau 編輯器：寫程式 → 按 F5 執行 → 右邊 3D 畫面立刻看到結果。程式不會上傳到任何地方，只存在這台電腦的瀏覽器裡。

執行與玩

  • F5 執行／繼續，Shift+F5 停止。每次執行都是全新的世界（底板 + 重生點），所有東西都由你的腳本建立。
  • 點一下 3D 畫面後：WASD 走路、空白鍵 跳、右鍵拖曳 轉視角、滾輪縮放。手機有虛擬搖桿。
  • 腳本種類：Script（伺服器，放 ServerScriptService）、LocalScript（玩家端，放 StarterPlayerScripts / StarterGui，用來處理鍵盤、GUI）、ModuleScript（用 require() 載入）。

除錯 Debug

  • 在行號左邊點一下設 中斷點 🔴，程式跑到那行會停下來，黃色箭頭 ➜ 是「下一個要執行的行」。
  • 停下來時：F10 下一行（不進入函式）、F11 進入函式、Shift+F11 跳出函式、F5 繼續跑到下一個中斷點。
  • 「變數 / 監看」分頁會列出當下所有區域變數，表格可以點 ▸ 展開；滑鼠移到程式碼裡的變數上也會直接顯示值。
  • 暫停時在底下 指令列 輸入 x = 100 可以直接改變數再繼續跑；沒暫停時指令列會在遊戲裡執行一段程式（像 Roblox 的 Command Bar）。
  • 勾選「出錯時暫停」，發生錯誤時會停在出錯那一行，讓你看當時變數是什麼。
  • 輸出視窗的紅色錯誤、藍色堆疊都可以點，會跳到對應的程式行；錯誤下面的橘色字是中文提示。

編輯器快捷鍵

  • Tab／Shift+Tab 縮排、Ctrl+/ 註解、Ctrl+S 存檔（其實隨時自動存）、Ctrl+Space 叫出自動完成。
  • 打 then、do、function() 後按 Enter 會自動補上 end。

支援範圍

直譯器是自己寫的 Luau：型別註記、continue、+=、字串插值 `{x}`、if 運算式、metatable、coroutine、string pattern 都支援。Roblox API 模擬了常用的部分：Instance / Part / Model / Folder、Vector3 / CFrame / Color3 / BrickColor / UDim2 / Enum、Players + 角色 + Humanoid、leaderstats 排行榜、Touched、TweenService、RunService、UserInputService、ContextActionService、ClickDetector、ProximityPrompt、ScreenGui / BillboardGui（TextLabel、TextButton、TextBox、Frame、UICorner、UIListLayout…）、RemoteEvent、BindableEvent、DataStore（存在瀏覽器）、Debris、Explosion、Raycast、CollectionService、HttpService JSON。

跟真的 Roblox 不同的地方：物理是簡化版（方塊碰撞、沒有旋轉翻滾）、只有一個玩家、伺服器和用戶端在同一個地方跑、沒有素材庫和模型匯入。寫好的程式可以「檔案 → 下載 .lua」或複製後貼進 Roblox Studio。
